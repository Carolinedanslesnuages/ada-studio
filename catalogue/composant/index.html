__NOM_PROJET__

Page de démonstration : le composant ci-dessous est intégré comme dans n’importe quel site.

Aucun choix pour l’instant.

L’intégrer dans une page

<script type="module" src="https://adresse-du-composant/composant.js"></script>

<composant-__SLUG__
  libelle="Rechercher une ville"
  elements='["Lille","Lyon","Nantes"]'
></composant-__SLUG__>

La page hôte peut suivre les choix (événement choix) et ajuster les couleurs :

document.querySelector('composant-__SLUG__')
  .addEventListener('choix', (evenement) => console.log(evenement.detail[0]))

composant-__SLUG__ { --composant-accent: #0f766e; }
