# Écrire une page

Une page est un fichier `.md` du dossier `site/`. Son adresse suit son chemin :
`site/guide/demarrer.md` devient `/guide/demarrer`.

## Titres

Un seul titre de premier niveau (`#`) par page, puis des sous-titres (`##`, `###`) sans sauter de
niveau : ils forment le sommaire « Sur cette page ».

## Encadrés

::: tip Conseil
Un conseil utile au lecteur.
:::

::: warning Attention
Un point de vigilance.
:::

## Images

Chaque image a un texte de remplacement qui dit ce qu’elle montre :
`![Schéma du parcours de demande](/schema.png)`. Une image décorative a un texte vide.

## Liens

Un lien dit où il mène (« [Démarrer](./demarrer) »), jamais « cliquez ici ».
